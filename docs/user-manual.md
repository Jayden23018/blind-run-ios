如果你是开发者或需要了解系统实现，请阅读 [技术与设计说明](technical-design-overview.md)，本手册不涉及技术细节。

本手册按"任务"组织，不按界面罗列功能。你想做什么，就直接跳到对应的小节：

每个操作步骤都是"一步一个动作"。步骤中提到的按钮，用的都是屏幕阅读器实际读出的名称，可以直接搜索。

### 无障碍说明

本手册本身按无障碍文档规范撰写：

## 1. 产品简介

### 1.1 助盲跑是做什么的

助盲跑（AidRun）是一款把**视障跑者**与**陪跑志愿者**匹配到一起的手机应用。视障跑者提出一次陪跑预约，系统自动派单给附近的志愿者，志愿者接单后到约定地点会合，陪同完成本次跑步。

### 1.2 它不做什么

明确说明边界，避免误解：

- **它不提供路线导航给视障跑者**。App 内的地图只用于视觉确认，不朗读转弯提示。跑步过程中的引导由志愿者本人完成。
- **它不能代替紧急电话**。求助功能会向平台记录事件，但**不保证救援到场**。情况危急请直接拨打 110 或 120。
- **它没有"现在就跑"**。所有预约的开始时间必须距离当前至少 30 分钟，用于留出派单和志愿者赶到的时间。
- **它不提供支付功能**。当前版本陪跑服务不涉及付费。

### 1.3 一次完整服务长什么样

```
视障跑者提交预约
        ↓
  系统派单中           ← 系统自动寻找志愿者
        ↓
   待出发             ← 志愿者已接单
        ↓
 志愿者出发中          ← 志愿者正在赶来
        ↓
 志愿者已到达          ← 双方在约定地点会合
        ↓
    进行中            ← 陪跑服务开始
        ↓
    已完成            ← 服务结束，可以评价
```

## 2. 开始之前

### 2.1 设备要求

| 项目 | 要求 |
|---|---|
| 系统 | iPhone，iOS 16 或更高版本 |
| 网络 | 需要联网，蜂窝网络或 Wi-Fi 均可 |
| 定位 | 必须开启，且需要授予 App 定位权限 |
| 麦克风 | 使用语音下单时需要 |
| 语音识别 | 使用语音下单时需要（系统"语音识别"权限） |

### 2.2 需要授予的权限

App 首次使用相关功能时会请求权限。**建议全部允许**，否则对应功能不可用：

| 权限 | 不授予的后果 |
|---|---|
| 定位（使用期间/始终） | 无法创建预约；志愿者无法接收派单 |
| 麦克风 | 无法使用语音下单和"问一句" |
| 语音识别 | 无法把你说的话转成文字 |
| 通知 | 收不到订单状态变化的提醒 |
| 相机（仅志愿者） | 无法完成活体认证和资质证书上传 |

如果误点了"不允许"，可以到系统「设置」→「助盲跑」中重新开启。

### 2.3 关于账号

- 使用**手机号 + 6 位短信验证码**登录，没有密码。
- 首次登录即自动注册。
- 一个手机号可以选择**视障跑者**或**志愿者**身份。
- 登录状态会保存，下次打开 App 无需重新登录。

## 3. 快速上手

### 3.1 视障跑者：五分钟约一次跑步

1. 打开 App，输入手机号，点击「发送验证码」。
2. 输入收到的 6 位验证码，点击「登录」。
3. 在角色选择页选择「视障跑者」。
4. 按提示填写昵称，并添加至少 1 位紧急联系人。
5. 完成实名认证（未完成前无法预约）。
6. 在首页点击「开始约跑」。
7. 听到提示后，用一句话说出你的需求，例如：**"明天早上八点从人民广场出发跑一个小时"**。
8. 听 App 复述你的预约内容，确认无误后说「确认」。
9. 等待系统派单。

### 3.2 志愿者：注册到接单

1. 用手机号登录，在角色选择页选择「志愿者」。
2. 填写姓名、手机号、身份证号，提交身份核验。
3. 完成活体认证（需要摄像头，按屏幕提示做动作）。
4. 上传资质证书，等待审核通过。
5. 审核通过后回到首页，**手动打开「可服务」开关**（默认关闭）。
6. 保持定位开启，等待系统派单。收到派单后在倒计时内点击「接单」。

## 4. 视障跑者指南

### 4.1 登录

1. 打开 App，进入登录页。
2. 找到「手机号输入框」，输入 11 位手机号。只能输入数字。
3. 点击「发送验证码」按钮。
   - 如果按钮读作"倒计时中"，说明服务端限制了发送频率，等倒计时结束再试。
4. 找到「验证码输入框」，输入收到的 6 位验证码。
5. 点击「登录」按钮。

### 4.2 首次完善信息

首次以视障跑者身份登录后，App 会引导你完成三件事。**前两件是必做的**，不完成无法进入首页。

#### 第一步：填写昵称

在「完善信息」页填写昵称，这是志愿者接单后看到的称呼。

#### 第二步：添加紧急联系人

在「紧急联系人」页添加联系人。规则：

- **至少 1 位，最多 3 位**。
- 必须**恰好有 1 位**被设为「主联系人」。
- 主联系人是求助时系统优先联系的人，也是首页求助条在非服务期间直接拨打的号码。
- 不能删除最后一位联系人。
- 不能直接删除主联系人，需要先把另一位设为主联系人。

每位联系人需要填写：姓名、关系、手机号。

#### 第三步：实名认证

实名认证页会读出当前状态和指引。你有两个选择：

- 点击「去实名认证」，填写姓名和身份证号提交。
- 点击「稍后再说」，先进入首页。

> **重要**：选择「稍后再说」可以浏览 App，但**在完成实名认证之前无法预约跑步**。可以随时在「设置」→「实名认证」中补做。

### 4.3 首页有什么

首页从上到下依次是（也是 VoiceOver 的朗读顺序）：

| 元素 | 说明 |
|---|---|
| 设置 | 进入设置页 |
| 盲人跑者首页 + 当前状态 | 朗读当前有无进行中的订单 |
| 位置摘要 | 当前位置或订单出发点 |
| 开始约跑 / 查看当前订单 | 没有订单时显示前者，有订单时显示后者 |
| 取消订单 | 仅在订单可取消时出现 |
| 问一句 | 语音提问，见 4.7 |
| 重复当前状态 | 重新朗读本页所有信息 |
| 一键求助 | 常驻，见第 6 章 |
| 辅助地图 | 仅供视觉确认，不可操作，排在朗读顺序最后 |

> **设计说明**：地图刻意排在朗读顺序的最后，让状态和主要操作先被读到。

### 4.4 约一次跑步（语音方式）

这是推荐方式。点击首页的「开始约跑」进入。

#### 第一轮：说出你的需求

App 会提示：

> 请说你想从哪儿出发、什么时候跑、跑多久，比如：明天早上八点从人民广场出发跑一个小时。说完再点一下就好。

说完后再点一下屏幕结束录音。你可以一句话说全部信息，也可以只说一部分。

**必须说到的信息**：预约时间。没有说时间的话，App 会提示"还没听到你说预约时间，现在不能下单"，并请你补充。

**可以说的信息**：出发地点、时长、是否带导盲犬、配速偏好、给志愿者的备注。没说的部分会用默认值。

#### 第二轮：地点消歧（仅在需要时出现）

如果你说的地点名称对应多个位置，App 会读出候选并请你选择：

> 找到 3 个地点，请说第几个。第一个……第二个……第三个……

回答「第一个」「第二个」或「第三个」即可。也可以说「重说」重新开始。

> 如果连续没听清，App 会**默认按第一个**处理，并明确告诉你："没听清是第几个，先按第一个来。"

#### 第三轮：确认

App 会复述完整的预约内容，然后说：

> 说「确认」就下单；要改哪一项直接说，比如「时间改成明天早上九点」；要整句重说就说「重说」。

你可以说：

| 你说 | 效果 |
|---|---|
| 确认 / 确认下单 / 没问题 / 就这样 | 提交订单 |
| 重说 / 重新说 / 重来 / 从头说 | 清空全部内容，从第一轮重来 |
| 重复 / 再念一遍 / 没听清 | 再念一次刚才的内容，不改任何东西 |
| 时间改成明天早上九点 | 只改开始时间，其余不变 |
| 跑半个小时 | 只改时长 |
| 从XX出发 | 只改出发地点 |
| 取消 | 放弃这次语音下单 |

> **注意**：「重说」是清空整句重来，「重复」只是再念一遍。两者容易说混，App 对这两组词做了严格区分。

#### 什么时候会自动切回表单

以下情况 App 会告诉你原因并切到表单填写，屏幕上的输入框仍可继续预约：

- 语音识别启动不了
- 连续两次没听到你说预约时间
- 同一项连续 3 次没听清
- 语音下单服务暂时不可用

### 4.5 约一次跑步（表单方式）

在语音页面点击「改用表单」，或语音不可用时自动进入。表单按步骤进行：

**第 1 步：出发地点**
默认使用当前位置（由高德地图解析成文字地址）。可以搜索其他地点。需要定位权限。

**第 2 步：预约时间**
选择开始时间。**必须至少在 30 分钟之后**，否则无法提交。

**第 3 步：选填需求**

| 字段 | 可选值 |
|---|---|
| 预计时长 | 按可选范围选择 |
| 配速偏好 | 走跑结合 / 轻松 / 中等 / 快速 / 无偏好 |
| 路线偏好 | 公园步道 / 街道 / 跑道 / 无偏好 |
| 是否携带导盲犬 | 是 / 否 |

这一步可以整步跳过，点击「不用填，直接下单」。

**第 4 步：提交**
确认信息后提交。

表单每一步都有「重复当前状态」按钮和「上一步」按钮。

### 4.6 等待与服务过程

提交后进入订单状态页，也可以从首页点击「查看当前订单」进入。

订单状态含义：

| 状态 | 含义 | 你能做什么 |
|---|---|---|
| 系统派单中 | 正在寻找志愿者 | 可以取消 |
| 待出发 | 志愿者已接单 | 可以取消；可以看到志愿者电话 |
| 志愿者出发中 | 志愿者正在赶来 | 可以打电话给志愿者 |
| 志愿者已到达 | 志愿者到了约定地点 | 会合 |
| 进行中 | 陪跑服务已开始 | **不能取消**；可以求助 |
| 重新匹配中 | 原志愿者取消了，正在重新派单 | 可以取消 |
| 暂无志愿者 | 没有匹配到志愿者 | 订单已结束 |
| 已完成 | 服务结束 | 可以评价 |
| 已取消 | 订单已取消 | — |

> **为什么进行中不能取消**：服务已经开始，中途需要的是求助或与志愿者沟通，而不是取消订单。这是刻意的设计。

订单状态页每 5 秒自动刷新一次，同时通过实时连接接收推送，两者互为兜底。

### 4.7 问一句

首页的「问一句」按钮让你用语音查询当前状态，不需要在界面里找信息。

点击后开始录音，你可以问：

| 你问 | 回答 |
|---|---|
| 志愿者还有多远 | 播报志愿者当前距离 |
| 现在什么情况 / 什么状态 | 播报订单状态 |
| 几点开始 | 播报预约时间 |
| 打电话给志愿者 | 二次确认后拨号 |

拨打电话前会先确认一次，避免误触。确认后才拨号，取消会播报"已取消拨号"。

### 4.8 结束与评价

服务完成后，订单状态页会显示「服务已完成」，并可以：

1. 选择 1 到 5 星评分（必填）。
2. 填写评价内容（选填）。
3. 点击「提交评价」。

也可以点击「跳过评价并返回首页」。

服务完成后还可以查看本次的路线摘要。

### 4.9 设置

在首页点击「设置」进入。可用项：

| 项目 | 说明 |
|---|---|
| 昵称 | 显示当前昵称 |
| 当前角色 | 显示"视障跑者" |
| 个人资料 | 编辑资料和紧急联系人 |
| 实名认证 | 查看状态、提交认证 |
| 关于 | 法律条款等 |
| 退出登录 | 需要二次确认 |
| 删除账户 | 永久停用账户，需要再次确认 |

## 5. 志愿者指南

### 5.1 注册与审核

志愿者需要通过审核才能接单。流程分三部分：

#### 第一步：基本信息与身份核验

填写：

- 姓名（必填）
- 手机号（11 位中国大陆手机号）
- 身份证号（18 位）

提交后系统核验身份信息。核验通过会提示"身份核验通过，请开始活体认证"。

> 注册操作有频率限制。提交过快会提示"注册操作过于频繁，请在 N 秒后重试"。

#### 第二步：活体认证

点击「开始活体认证」，按屏幕提示完成面部动作。需要相机权限。

如果失败，App 会给出具体原因，例如：

- 相机权限未开启
- 网络连接失败
- 设备时间不准确（需要校准系统时间）
- 流程重复发起（稍后重新开始）

可以点击「重新开始活体认证」重试。

#### 第三步：上传资质证书

在首页点击「上传资质证书」进入。**资质审核通过后才能接单**。

### 5.2 开启接单

> **重要**：志愿者的「可服务」开关**默认关闭**。注册审核通过后，必须手动打开才会开始收到派单。

关闭开关不影响已经接下的订单。

同时需要：

- **保持定位开启**。定位关闭时会提示"定位未开启，系统派单不可用"，收不到派单。

### 5.3 接单

本平台采用**系统派单**，不是抢单。系统会把订单派给合适的志愿者。

收到派单时：

1. App 语音播报"新订单到达，请在 N 秒内响应"。
2. 在倒计时内点击「接单」或拒绝。
3. 接单前会确认一次："确认接单后将显示盲人联系方式。"

> **隐私设计**：接单前看不到视障跑者的联系方式、紧急联系人和敏感健康信息，接单后才展示完整手机号。

首页的派单状态面板可以上滑展开、下滑收起，显示当前派单状态和位置覆盖摘要。

### 5.4 服务流程

接单后进入订单页，按顺序完成五个动作：

| 顺序 | 按钮 | 什么时候点 |
|---|---|---|
| 1 | 导航到出发地点 | 需要路线时，会调起外部地图做步行导航 |
| 2 | 我已出发 | 你开始前往约定地点时 |
| 3 | 我已到达约定地点 | 你到达会合点时，会通知视障跑者 |
| 4 | 开始服务 | 与视障跑者会合、准备开始跑步时 |
| 5 | 结束服务 | 本次陪跑完成时 |

各阶段的页面提示：

| 阶段 | 提示 |
|---|---|
| 待出发 | 请确认当前位置和出发地点，可使用外部地图步行导航 |
| 出发中 | 请按导航前往出发地点，盲人跑者正在等待 |
| 已到达 | 已到达集合地点，请点击开始服务，服务开始前不能结束订单 |
| 进行中 | 完成本次陪跑后可结束服务 |
| 已完成 | 感谢您的爱心陪伴 |

> **顺序约束**：不能跳步。服务未开始不能结束；服务已完成不能重复结束。App 会明确告诉你原因，例如"当前订单状态尚未到达约定地点，不能开始服务"。

如果操作后状态迟迟没确认，页面会提示"状态确认延迟，请稍后点击『重新确认状态』。请勿重复提交同一操作。"——**不要重复点同一个按钮**，用「重新确认状态」。

### 5.5 志愿者取消订单

志愿者可以在「待出发」「出发中」「已到达」「进行中」阶段取消订单。取消后订单进入**重新匹配中**状态，系统会重新派单。

> 取消后你就不再是这个订单的参与者，之后只有视障跑者本人能取消该订单。

### 5.6 积分

每完成一次服务获得 **+100 积分**。

积分商城功能尚未上线，页面显示"积分商城即将上线，敬请期待"。

### 5.7 设置

与视障跑者类似，包含个人资料、退出登录、删除账户。

删除账户时，系统会先检查是否存在进行中的服务，检查通过后仍需再次确认。

## 6. 安全与求助

### 6.1 求助按钮在哪

**视障跑者**：首页有一条常驻的「一键求助」。
**志愿者**：仅在服务「进行中」时开放求助入口。

### 6.2 两种不同的行为（务必分清）

首页的求助条会根据当前状态走**两条完全不同的路径**：

#### 情况 A：服务进行中

走平台求助流程：

1. 二次确认，确认文案是：
   > 是否确认进入求助状态？确认后，本次服务将标记为异常，系统会记录当前订单状态。
2. 确认后 App 获取你的当前位置。
3. 向平台发送求助并上报位置。
4. 播报处理进展。

#### 情况 B：其他任何状态（没有进行中的服务）

**降级为本地拨号**。按下后 App 只会调起电话，拨给你的主紧急联系人或 110。

> **App 不会代你发送求助。** 这种情况下按下按钮只有拨号，平台不会收到任何记录。App 会明确告诉你这一点。

### 6.3 求助必须有位置

云端求助需要**新鲜的真实位置**。拿不到位置时求助**不会发出**，App 会同时用文字和语音告诉你：

> 求助未发出：当前无法获取你的位置。请在设置中允许定位后重试，或直接拨打110。

这是刻意的设计——一条没有位置的求助对救援没有帮助，不如让你立刻知道并改打电话。

### 6.4 求助之后会发生什么

App 会按后台的实际进展播报，可能听到：

| 提示 | 含义 |
|---|---|
| 已收到你的求助，系统正在处理 | 平台已记录 |
| 求助已记录，正在通知同行志愿者确认情况 | 正在联系同行志愿者 |
| 系统正在联系你的紧急联系人，尚未确认对方是否收到 | 正在发短信，**结果未知** |
| 你的紧急联系人已收到求助短信 | 短信确认送达 |
| 联系紧急联系人失败，对方没有收到短信。请立即拨打110或120 | 短信失败 |
| 求助已记录，已转由客服处理 | 客服接手 |

> **重要原则**：在收到明确的送达确认之前，App **不会**说"已通知家属"。看到"正在联系"就是字面意思——还没确认对方收到。**所有求助提示后面都会跟一句"若情况危急请立即拨打110。"**

### 6.5 撤销求助

只有**受助者本人**可以撤销求助，按钮是「撤销求助」。撤销确认文案：

> 确认撤销本次求助？系统会给已通知的紧急联系人补发一条解除短信。

**志愿者不能撤销求助。** 这是刻意的安全设计：一对一陪跑中志愿者可能就是威胁来源，因此撤销权只在受助者本人和平台客服手里。志愿者能做的是点击「确认需要帮助」，协助确认情况。

### 6.6 求助有冷却时间

刚发过求助后短时间内不能重复发送，会提示"刚刚已经发送过求助，请 N 秒后再试"。

### 6.7 服务过程中的安全提示

服务进行中，App 可能给出信息性提示，例如距离异常或信号丢失。

> 这些提示**只是提醒**，不改变订单状态，也**不代表救援已经派出**。需要帮助请使用求助功能或直接拨打 110。

如果定位或网络出问题，App 会在屏幕底部提示并语音播报：

- "设备位置暂时不可用，已暂停同行位置共享。"
- "定位权限已关闭，同行位置与路线记录已暂停，请前往系统设置开启。"
- "网络连接已中断，同行位置将在重连后自动恢复。"

## 7. 常见问题

**问：为什么不能约"现在就跑"？**
答：所有预约的开始时间必须至少在 30 分钟之后。这段时间用于系统派单和志愿者赶到约定地点。

**问：我完成实名认证了吗？怎么查？**
答：进入「设置」→「实名认证」，页面会读出当前状态。

**问：为什么我点了"稍后再说"还是不能约跑？**
答：实名认证是预约的前置条件。跳过只是让你先进入首页浏览，预约仍然需要先完成认证。

**问：语音下单一直听不清怎么办？**
答：连续听不清时 App 会自动切换到表单填写，并告诉你原因。也可以随时说「重说」，或点击「改用表单」。

**问：「重说」和「重复」有什么区别？**
答：「重说」= 清空全部内容从头再说一遍；「重复」= 只是把刚才的内容再念一次，不改任何东西。

**问：我说了地点，但 App 说找到好几个？**
答：说明这个地点名称在附近对应多个位置。听完候选后回答「第一个」「第二个」或「第三个」。

**问：为什么服务进行中没有取消按钮？**
答：这是刻意的。服务已经开始时，你需要的是求助或与志愿者沟通，而不是取消。

**问：志愿者取消了我的订单，怎么办？**
答：订单会自动进入「重新匹配中」，系统重新派单。这期间你仍然可以取消订单。

**问：我是志愿者，为什么收不到派单？**
答：依次检查三件事：① 资质审核是否通过；② 首页的「可服务」开关是否打开（**默认是关闭的**）；③ 定位权限是否开启。

**问：我是志愿者，误点了状态按钮怎么办？**
答：状态只能按顺序前进。如果点错导致状态不对，请联系平台客服处理，不要反复点击按钮。

**问：按了求助，家属会收到短信吗？**
答：平台会尝试发送，但 App 在收到明确送达确认之前**不会**告诉你"已通知"。听到"正在联系你的紧急联系人，尚未确认对方是否收到"就是字面意思。**情况危急请直接拨打 110。**

**问：地图能给我导航吗？**
答：不能。App 内的地图只用于视觉确认，不朗读转弯提示。视障跑者的引导由志愿者本人完成。志愿者可以调起外部地图做步行导航。

## 8. 提示语对照表

App 里听到这些提示时的处理方法：

| 提示语 | 含义 | 该怎么做 |
|---|---|---|
| 需要开启定位权限后才能创建预约 | 定位未授权 | 到系统设置开启定位 |
| 当前状态加载失败，请重试 | 网络或服务异常 | 点击「重试加载」 |
| 加载超过 20 秒，请重试 | 请求超时 | 检查网络后重试 |
| 订单状态尚未确认，请先重试加载，避免创建重复预约 | 状态未知，防重复下单 | 先刷新状态，不要直接下单 |
| 当前订单状态不能由盲人取消 | 订单已进入不可取消阶段 | 联系志愿者或使用求助 |
| 这次没能把你说的话转成预约内容，下面念的是默认值 | 语音解析失败 | 听完默认值后逐项修改，或说「重说」 |
| 没找到你说的那个地点，出发地先按当前位置来 | 地点识别失败 | 说「重说」重新说，或改用表单 |
| 你说的是 N 分钟，超出了可预约范围 | 时长超限 | App 已自动按最接近的可选值处理 |
| 语音下单暂时用不了 | 语音服务不可用 | 已自动切到表单，继续填写即可 |
| 求助未发出：当前无法获取你的位置 | 没有位置，求助未发送 | **立即拨打 110**，并检查定位权限 |
| 刚刚已经发送过求助，请 N 秒后再试 | 求助冷却中 | 危急情况直接拨打 110 |
| 定位暂不可用，可能无法收到派单（志愿者） | 定位异常 | 检查定位权限和信号 |
| 状态确认延迟，请稍后点击"重新确认状态" | 操作已提交但未确认 | 点「重新确认状态」，**不要重复提交** |
| 活体认证 SDK 未配置，请更新客户端后重试 | 客户端版本问题 | 更新 App |
| 注册操作过于频繁，请在 N 秒后重试 | 触发频率限制 | 等待后重试 |

## 9. 术语表

| 术语 | 含义 |
|---|---|
| 视障跑者 | 需要陪跑服务的视力障碍用户，App 内也称"盲人跑者" |
| 志愿者 | 提供陪跑服务的用户 |
| 系统派单 | 平台自动把订单分配给合适志愿者的机制，区别于志愿者主动抢单 |
| 可服务 | 志愿者的接单开关，打开后才会收到派单，**默认关闭** |
| 活体认证 | 通过摄像头验证操作者是真人本人的过程 |
| 资质证书 | 志愿者需要上传并通过审核的证明材料 |
| 主联系人 | 紧急联系人中被标记为优先联系的那一位，有且只有一位 |
| 重新匹配中 | 志愿者取消后订单重新寻找志愿者的状态 |
| 求助 | 独立的安全事件，**不是订单状态**，不改变订单进程 |
| VoiceOver | iOS 系统自带的屏幕阅读器 |

## 10. 获取帮助

### 遇到问题时请提供

联系平台时，说明以下信息能大幅加快处理：

1. 你的角色（视障跑者 / 志愿者）
2. 出问题的时间
3. 订单当时的状态（例如"待出发"）
4. App 说了什么（尽量复述原话）
5. 你做了什么操作

### 紧急情况

**任何危及人身安全的情况，请立即拨打 110（治安）或 120（医疗）。**

App 的求助功能是平台记录和联系流程，**不是急救调度系统**，不保证救援到场。
