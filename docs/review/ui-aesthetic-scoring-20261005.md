## 改了什么

**第一轮**（不与任何决定冲突）：帮助页藏标签栏（「知道了」被盖住）；语音面板「轻点开始说话」改白底实心胶囊；跑者通话确认页次按钮改描边、「换一位」不再用红（`OutlineSecondaryButtonStyle` 提到 DesignSystem，并显示禁用态）；订单副标题的距离换行；「您」→「你」。

**第二轮**（负责人 2026-10-05 逐项拍板）：陪跑完成页加国标星级进度卡；成就页主数字卡主色实心、勋章改圆形徽章（AX 档退回逐行）；两端「我的」标签根页标题「我的」+ 个人卡（跑者本月 0 次时不显示）；汇合页无方向时不画方位盘（偏离设计源，已记 `docs/ui/mockups/INDEX.md`）。OpenSpec `enrich-completion-and-profile-tab`。

**没做、为什么**：完成页「本次计入志愿时长」（后端没有按单服务分钟字段）；成就页列未解锁勋章（契约只给已解锁的，写死名称是第二个源）。
