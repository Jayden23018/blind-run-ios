## 改了什么

**第一轮**（不与任何决定冲突）：帮助页藏标签栏（「知道了」被盖住）；语音面板「轻点开始说话」改白底实心胶囊；跑者通话确认页次按钮改描边、「换一位」不再用红（`OutlineSecondaryButtonStyle` 提到 DesignSystem，并显示禁用态）；订单副标题的距离换行；「您」→「你」。

**第二轮**（负责人 2026-10-05 逐项拍板）：陪跑完成页加国标星级进度卡；成就页主数字卡主色实心、勋章改圆形徽章（AX 档退回逐行）；两端「我的」标签根页标题「我的」+ 个人卡（跑者本月 0 次时不显示）；汇合页无方向时不画方位盘（偏离设计源，已记 `docs/ui/mockups/INDEX.md`）。OpenSpec `enrich-completion-and-profile-tab`。

**没做、为什么**：完成页「本次计入志愿时长」（后端没有按单服务分钟字段）；成就页列未解锁勋章（契约只给已解锁的，写死名称是第二个源）。

## 改后自读（逐屏对照改前）

第一轮 5 处、第二轮 4 处都到位。剩下看得出的问题：盲人已完成屏「本次路线」在地图关闭时只剩标题；成就页只有一枚勋章时一排四格偏空；「我的」页设置列表底部仍被求助条 / 标签栏压住最后一行（改前就有）。

涨的主要是易用（通话确认 7 → 9、帮助页 5 → 6）；吸引力动得少。打分员第二轮「最该改」的前几条，供下一轮分诊（**未核对，照例先对着代码与既有决定核**）：

1. 陪跑完成页：先给本次数据与一句感谢，星级改正向说法（「已累计 2 小时」+ 更近的小目标）；它又提「去掉求助」—— 与 AGENTS §6 冲突，不动。
2. 盲人完成页：「完成 / 提交评价 / 跳过评价 / 设为固定搭档」四个动作抢主位，「服务已完成」「本次路线」标题下为空（后者含地图关闭因素）。
3. 志愿者首页：评分、完成次数、培训提醒各重复一次；接单率 / 拒绝 / 超时像在考核无偿志愿者。
4. 盲人跑步中：底部固定区约占 28%，第三个节奏按钮要滚才看得到；它提「跑步中隐藏标签栏」。
5. 盲人订单页底部固定区把最后一行信息拦腰切开（集合地点只露半截）。
6. 语音聆听中与待说态几乎一样，看不出在不在听（B07 截的是 UI 测试接缝，**不是真录音态**，先核）。
7. 盲人空首页 70% 空白；8. 志愿者通话确认页信息少、倒计时埋在灰字；9. 志愿者「我已经出发了」是描边按钮（DECISIONS-v2 范围，先查）；10. 登录页空、禁用按钮对比度低。
