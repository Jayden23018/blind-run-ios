## 时间闸（决定了节奏，来源：后端 `docs/api_spec.yaml` 的接口描述，数值是**默认值，生产实际配置未核**）

| 闸 | 规则 | 对演示的影响 |
|---|---|---|
| 下单提前量 | 开跑时间 ≥ 当前 + 30 分钟（`APPOINTMENT_TOO_SOON`） | 没有「现在就跑」；开跑时间 P 取下单后约 32 分钟 |
| 出发 | 最早 P − 60 分钟（`DEPARTURE_TOO_EARLY`） | P 取 +32 分钟时，下单后立刻可点 |

| 志愿者临期确认 | 仅跨天预约（`SCHEDULED_CONFIRMED`，开跑前 120 分钟内才能确认） | 30 分钟后的单走不到，**「约好·前一晚」画板现场演不了**，用渲染出的设计稿 PNG 展示 |

## 红线（来自 `AGENTS.md` §5–§6，演示时照做）

- **不要长按 3 秒。** 跑者端求助中心与志愿者端 `FlowHelpPill` 的紧急按钮，长按 3 秒是**直发云端求助**，会真的通知联系人；轻点 / 读屏双击才是弹确认框，确认框文案逐字锁定。
- **不得说「短信已发出 / 联系人已被通知」**，也不得让屏幕上出现 `联系人已收到短信`。
- **志愿者端只显示掩码号**，不能把它拼进拨号；演示时不要点拨号。
- 盲人的自由文本在 `PENDING_INTRO_CALL` 对志愿者**不可见**，这是设计，别当缺陷讲。
- 这是 Demo Cloud 真后端：演示产生的订单与位置是真写入的。

## 录制与交付

**一次真机实跑，同时产出两样东西**：① 一条能发给别人的成片视频（主交付）；② 之后从同一份素材抽帧做的「设计稿 | 真机」走查页（辅助，帧来自录屏，不用另外截图）。

### 怎么录（负责人操作；按上面「演示流程」走一遍）

1. 两台设备都用 **iOS 控制中心「屏幕录制」**（麦克风保持关）。不用 QuickTime：不占 USB、不用两个窗口，且系统录屏录的是设备内部音频（该报告第 114 行只确认了 **VoiceOver 声音**会被录到；**App 自己的 TTS 播报是否入轨未核**，要靠先试拍 15 秒确认）。
2. 先登录：iPhone = 联调盲人号，iPad = 联调志愿者号（验证码 `000000`）；志愿者端打开接单开关并给定位权限。
3. **两台同时开始录**，然后从步骤 1 一路走到步骤 12。**步骤 6 的空档不用停录**，剪辑时整段剪掉。
4. 步骤 9（求助）只轻点到确认框、点取消；**不要长按 3 秒**。
5. 录完停止，两条录屏用 AirDrop 发到 Mac（或数据线拷出），**原文件别压缩、别裁剪**。
6. 已知局限：系统录屏**不显示手指触点**（`real-device-demo-walkthrough-20260930.md` §3.2），成片靠字幕标「点击 xx」补；iPad 上 App 是 iPhone 版放在 iPad 屏中间，剪辑时裁掉黑边。

### 成片规格（发给人看，不上 App Store）

| 项 | 取值 | 依据 |
|---|---|---|
| 画幅 | 1920×1080 横版，左右并排：左 iPhone（盲人端）、右 iPad（陪跑员端，裁成手机比例） | 两端同屏才能看出「一边点、另一边响应」 |
| 时长 | 2~3 分钟：下单到汇合约 1 分钟，服务开始之后约 1 分钟，中间的空档用「约 15 分钟后」文字卡带过 | 官网首页 60~90 秒、详情页 90 秒~3 分钟（`demo-video-production-20260814.md`） |
| 字幕 | **烧进画面**（不是外挂 srt） | 手机播放器默认静音，微信里尤其如此；Apple 对 App Preview 的同一条要求是默认静音播放 |
| 声音 | 保留设备内部声音，不加配乐；**若试拍发现 TTS 没录进去，改为剪辑时把播报文字做成字幕** | 播报本身就是这个 App 的卖点 |
| 格式 | `.mp4`，H.264 + AAC | 微信 / 邮件 / 会议共享都能直接打开 |

### 跟「App Store 里点进去看的那种视频」的关系

那是 **App Preview**：上架后在商店页展示，规格是硬的（15~30 秒、竖屏 886×1920、只能有 App 内画面、**禁止拍手指**，见 `demo-video-production-20260814.md` §1），而且要上架才有位置。**现在只是发给别人看，不受这些规格限制**；等上架再从同一份素材剪一条 ≤30 秒的纯录屏版。两条是两个文件，别混用。

### 谁来做什么

- 负责人：录屏、AirDrop。
- 我：拿到原片后剪辑（对齐、剪空档、并排、烧字幕、导出 mp4）、抽帧做走查页、过一遍红线（画面里不得出现 `联系人已收到短信`、不得露出志愿者端的完整号码）。
