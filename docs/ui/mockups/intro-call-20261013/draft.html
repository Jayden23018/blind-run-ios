「先通个电话」通话页重设计 · 初稿（2026-10-13）

两端通话页并进订单页同一套样式：同样的顶栏、头卡、引导绳、信息卡、底部按钮；颜色全部是已有的，没有新增。 通话这一步仍属「匹配」，人还没定下来，所以头卡是匹配阶段的白卡、引导绳是虚线。 订单页新加的「四步进度」在通话页也有，用户随时知道自己在哪一步、前面走过什么、后面还有什么。
⚠️ 两条规则原样保留：不显示对方的表态，不显示「这是第几位志愿者」（说了就等于告诉盲人前面几位没成）。
