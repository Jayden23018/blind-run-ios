这一单没约成自动回到首页，播报「这次通话确认已结束，感谢你的响应」。不说是谁、为什么。
保留的规则　不显示对方的表态 · 不显示「第几位志愿者」 · 陪跑员端号码只显示打码版本、不能回拨 · 「一直没接到电话」与「不合适」是两个动作 · 没约成不说原因。
读屏　绳子念「第 N 步，共 4 步，＋当前状态」，头卡里不再写这句，免得念两遍。
其他　图标为示意，实现用 SF Symbols；名字和数字是示例。最大字号下绳子等比放大、文字换行不截断；「减弱动态效果」打开时头像直接跳格。陪跑员端汇合与完成页用同一张插图（左边是陪跑员自己）。
