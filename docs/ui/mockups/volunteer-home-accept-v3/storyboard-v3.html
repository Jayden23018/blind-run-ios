陪跑员端：首页与接单

草图第 3 版，沿用跑者端的视觉语言：订单一个页面贯穿全流程，底部只有一个黄色主按钮和求助与安全。人名、地点与跑者端故事板保持一致（跑者李明，陪跑员张伟）。

v3 的产品决策

  1. 主页与接单分开：打开 App 先到主页，看到陪跑次数、已认证时长、一起跑过的跑者和奖章，滑动后进入接单主页。
  2. 准入：强制两步，实名认证（含志愿者须知、风险告知）和线上课程；仅限 18 岁以上。
  3. 设置归位：空闲时间、出发地、交通方式、愿意去多远，放在“我的”。
  4. 匹配：系统在空闲时间内定向邀请，一起跑过的优先；3 小时没人接，进入“附近还没人接的”。
  5. 订单页：邀请 → 约好 → 出发 → 汇合，与跑者端四步一一对应，原地变化。
  6. 汇合：陪跑员去找跑者，显示方位、距离、衣着；到达由陪跑员手动确认。
  7. 取消：开始前 12 小时内取消记临时取消；跑者取消或陪跑员等满 15 分钟，不算陪跑员的。
  8. 新邀请：后台用推送；在接单主页从底部弹出邀请卡；在其他页面用顶部横幅；陪跑进行中先暂存，结束后再出现。
  9. 时长：从开始跑步到结束陪跑，标“待认证”，组织 10 个工作日内确认；不出现升学、评优字样。

  • 陪跑员“接单中”状态、空闲时间、临时取消计数由后端保存；时长以服务端的开始、结束时间为准。
  • 实名认证提交后，组织在后台确认志愿者意外险生效，才对该陪跑员发邀请。
