日期用哪种：选参考图 2 的「一排日期」，不选图 1 的月历

1. 能约的只有 7 天。后端最远只收 7 天内的预约。月历一屏 30 多格，四分之三是灰的不能点，低视力用户要在一堆灰格里找那几格亮的。

2. 读屏走月历很慢。读屏是一格一格往右划，月历要先划过星期表头、上月空格、已过的日子，才到今天；一排 7 个日期，划 1 下就是明天。

3. 月历格子太小。一行 7 格，每格约 48 点宽，低于我们盲人端 64 点的可点下限。

但不照抄图 2 的横向滑动。滑出屏幕的日期低视力用户看不到、读屏也常漏掉。7 天直接排成两行大按钮（4 + 3），字号放到最大时自动换成更多行。

时段照两张图都有的「上午 / 下午 / 晚上」。不要图里下面那排 9:00、9:30……具体时刻，这一步您说了盲人不用选。「晚上」改叫「傍晚」并止于 21:00，因为 22:00 以后不能跑。

和 v1 比：v1 是三个「今天稍后 / 明天早上 / 明天傍晚」点了就发；v2 能约 7 天内任意一天，多了一个主按钮，代价是至少点两下（默认值合适时一下）。
