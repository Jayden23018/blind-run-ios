## 决定

1. **两屏照盲人 v8**：浅灰底 + 白卡；彩色卡在两屏同一个位置、同一个大小（陪跑中青绿、跑完了绿，渐变同盲人端 `BlindRunCardsPalette`）。不放地图。
2. **跑步中**：标题「陪跑中」+「和李*一起 · ● 定位正常」→ 青绿卡（里程大字、用时、每公里配速）→「耳机语音播报」开关卡 →「让李的手机响起来」卡；收不到对方位置等提示保留，作为一张卡放在彩色卡正下方。底部「长按 2 秒，结束陪跑」藏青胶囊。顶部圆形 ‹ + 红色实心「求助」。
3. **跑完了**：标题「跑完了」+ 副标题 → 绿卡（同一位置）→ 路线小图 → 跑者卡（头像、名字、「全盲 · 牵引绳」、右边「上报问题」）→ 国标星级卡 →「查看跑步记录 ›」；底部「完成」藏青。
4. **按钮藏青**（`AppColors.Flow.navy`），与盲人端订单页一致。
5. **业务规则不变**：长按 2 秒结束、跑步中求助面板（暂停、让跑者手机响、联系客服、长按 3 秒紧急求助）、暂停态、走散提醒、语音播报、跑完后的数据加载与失败重试。

## 实现时的取舍（负责人未逐条看过）

- **跑完了副标题**：照稿写起止时间「今天 7:02–7:44」。订单详情里没有开跑 / 结束时刻，取跑者轨迹（`/track` 的 `blindTrack`）第一个点和最后一个点的记录时刻；轨迹没拉到或不足两个点时退回「和李*一起 · 第 N 次」（一起跑过两次以上才写次数）。
- **跑完了显示配速**：稿上有，照稿显示。这改了陪跑员订单页 v2 交付包 D11「完成页不显示配速（不暗示表现）」。
- **跑完了有返回键**：照稿圆形 ‹ 加「···」，同盲人端 v8 ⑧（改 v7「完成页出口只有主按钮『完成』」；调度审查 2026-11-12 指出）。
- **计划进度卡**：稿上没画。订单填了计划里程时，跑步中彩色卡下面照盲人 v8 出「计划跑 N 公里」进度卡（替代旧抽屉里的目标进度条）；没填不出现。
- **暂停中**：「继续跑步」是唯一的实心藏青按钮，「长按结束」退成灰底描边（一屏只有一枚实心）。
- **最大字号**：彩色卡用时、配速改上下排（同盲人 v8 第二排）；跑者卡的「上报问题」排到名字下面。
