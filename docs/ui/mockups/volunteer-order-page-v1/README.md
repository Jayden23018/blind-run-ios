## 给 Claude Code 的开场指令

先让它读现有代码，再动手。现有项目：iOS 原生（已有基础 UI），后端 Spring Boot（已有 WebSocket GPS 追踪、紧急求助、志愿者认证，部署在阿里云 ECS）。本包里的类名、接口路径、字段名都是**建议**，和现有代码冲突时以现有代码为准，并在 PR 说明里写清楚映射关系。

**后端（先做，前端依赖它）：**

```
读 handoff/README.md、00-decisions.md、05-backend.md、06-api-contract.md、07-acceptance.md。
先梳理现有代码里的订单状态机、订单实体、推送和 WebSocket 实现，输出一份"现有 vs 本包"的差异表给我确认，不要直接改。
确认后按 05 和 06 实现，每个新增能力都要有单元测试，现有 116 个测试必须保持通过。
```

**前端 iOS：**

```
读 handoff/README.md、00 到 04、06、07。
先梳理现有 SwiftUI 工程里订单页、设计常量、网络层的结构，给我一份改造计划，不要直接改。
确认后：先实现 01 里的 DesignTokens 和通用组件（附 SwiftUI Preview），再实现 RopeView 及其动画，最后按 02 逐个状态接入订单页。
后端接口未就绪时用 06 里的 DTO 写 mock，所有状态都要有 Preview。
```

## 本期范围

包含：订单页的邀请、约好（前一晚 / 出发前 30 分钟）、出发、快迟到、汇合、等待满 15 分钟、完成、跑者取消；锁屏实时活动；相关后端能力。

不包含：跑步中（以《跑步中与跑后》规格为准，保持现有实现）、首页 A1–A5、邀请弹卡 B1–B10（沿用 v3，只替换设计常量）、深色模式、安卓。
