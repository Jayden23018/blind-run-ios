# 07 · 验收清单

每一项都要能在 PR 里给出证据：测试名、Preview 截图或录屏。

## 后端（单元测试 / 集成测试）

**状态机**
- [ ] 每个合法迁移成功，每个非法迁移返回 `409 INVALID_STATE` 并附当前状态
- [ ] 两名陪跑员同时 `accept`：只有一个成功，另一个得到 `409 ORDER_TAKEN`
- [ ] 双方同时 `start-run`：订单只进入一次 RUNNING，两次调用都返回 200
- [ ] `end-wait` 在等待 14 分 59 秒时被拒绝，15 分钟时成功
- [ ] 现有 116 个测试全部通过

**时间计算**
- [ ] start 7:00、travel 20 分钟 → suggestedDepartAt 6:35、departReminderAt 6:30、primaryActionUnlockAt 6:05
- [ ] 修改出发地或交通方式后，未出发的订单重新计算以上三个时间

**ETA 与晚到**
- [ ] 剩余时间从 8 分钟变为 7.6 分钟（取整后不变）时，不发 `order.eta_updated`
- [ ] 预计晚到 4 分钟时自动通知跑者一次；变成 5 分钟不再通知；变成 8 分钟再通知一次；回到 2 分钟时发一次"恢复准时"
- [ ] progress 始终在 0.1 到 0.85 之间

**汇合**
- [ ] 距离档位的边界值：d+e = 10、50、100 以及位置超过 60 秒未更新
- [ ] 跑者关闭位置共享时：不转发 `meet.runner_location`，`sharingEnabled = false`

**新能力**
- [ ] 响铃：非 ARRIVED 状态 409；10 秒内第二次调用 429；第 21 次调用 429；跑者端离线时退化为 APNs
- [ ] 快捷回复：同一 type 60 秒内第二次 429；不同 type 不受影响
- [ ] 留言与偏好：超长文本被拒绝；敏感词被过滤；INVITED 时 view 接口不返回留言

**隐私**
- [ ] INVITED 状态的 view 不包含全名、电话、留言、位置
- [ ] 订单终止后不再转发任何位置
- [ ] 实时活动推送载荷和锁屏推送中只有姓氏

**实时活动**
- [ ] ContentState JSON 能被 04 里的 Swift 结构直接解码（后端提供一份样例 JSON，iOS 端写解码测试）
- [ ] 完成或取消时发送 `end`
