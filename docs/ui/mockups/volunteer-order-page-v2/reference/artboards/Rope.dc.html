状态色与引导绳
每个状态一个头卡颜色，读顺序是一段早晨：藏青的夜 → 出门的蓝 → 见面的暖 → 一起跑的青绿 → 完成的绿。页面底和卡片保持浅色；颜色只出现在头卡上，所以不会乱。引导绳在所有彩色头卡上用同一套画法：陪跑员是实心白圆，跑者是白色描边圆，绳子是白色，并肩后变金色。
