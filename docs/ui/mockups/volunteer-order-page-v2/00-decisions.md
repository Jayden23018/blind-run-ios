# 00 · 相对 v3 的改动与待定事项

## 一、已决定的改动

| # | 改动 | v3 原来 | v2 现在 | 原因 |
|---|---|---|---|---|
| D1 | 求助入口 | 每屏底部通栏浅红按钮，与黄色主按钮上下相邻 | 所有订单页导航栏右上角同一个带文字的「求助」胶囊按钮；底部不再有红色按钮 | 紧急入口必须位置固定；避免骑车 / 小跑时误按主按钮 |
| D2 | 进度表达 | 文字四步条「邀请 · 约好 · 出发 · 汇合」 | 头卡内的「引导绳」：两个头像之间的距离 = 还要走多远；步骤只给读屏 | 让"两个人在靠近"成为第一眼看到的信息 |
| D3 | 引导绳语义 | — | 虚线 = 还没约好；实线 = 已约好；不画走过的路 | 一个符号只表达一个意思 |
| D4 | 约好页主按钮 | 「我出发了」始终是黄色主按钮 | 出发前 30 分钟以外：白色次要按钮「我已经出发了」；出发前 30 分钟起：黄色主按钮「我出发了」 | 前一晚看到"现在不该按"的主按钮没有意义；v3 的"随时可按"仍然成立 |
| D5 | 头卡 | 白底，58pt 头像 + 24pt 时间 | 统一藏青 `#1B2657` 头卡（邀请除外，仍为白色），每个状态一个主角数字 | 订单页是全流程主角；收拢配色 |
| D6 | 快捷语音 | 「我到入口了」「再等我 5 分钟」 | 「我快到了」「再等我 5 分钟」 | 原文案与「我已到达集合点」语义重叠 |
| D7 | 汇合距离 | 「约 40 米」精确数字 + 70pt 方位盘 | 粗粒度距离（「大约 50 米以内」等），方位用扇形表示大致方向，去掉东南西北刻度 | 公园内 GPS 误差 10–30 米，精确数字会误导 |
| D8 | 让跑者手机响铃 | 无 | 汇合页新增「让李明的手机响起来」；跑者端响铃并播报"你的陪跑员到了" | 视障跑者无法主动找人，但可以被声音找到 |
| D9 | 跑者写的偏好与留言 | 通用的「引导习惯」两行 | 显示跑者用自己的话写的「写给陪跑员」；约好后跑者可给陪跑员留一句话 | 更实用，也更有人情味 |
| D10 | 集合点地标 | 只有集合点名称 | 名称 + 地标描述（如「石牌左边的空地」），由组织在后台录入 | 地标信息不能来自视障跑者 |
| D11 | 完成页 | 绿勾 + 时长卡 + 主按钮「完成」 | 关系标题「你和李明第 N 次一起跑」+ 留言最显眼 + 主按钮「回复李明」，「完成」降为灰色文字；去掉配速大数字与每次都出现的奖章 | 情感高点接到下一步；不暗示"表现" |
| D12 | 时长说明 | 「组织会在 10 个工作日内确认」 | 加上算法：「从开始跑步算到结束陪跑」 | 避免"赶路没被算"的误解；规则本身不变 |
| D13 | 字号 | 关键信息有 12–13pt | 关键信息不小于 14–15pt，13pt 只用于非关键标签 | 户外强光可读性 |
| D14 | 黄色主按钮 | 纯色 | 加 1.5pt `#D9A21E` 描边与暖色阴影 | 浅灰底上边界对比约 1.5:1，强光下会"消失" |
| D15 | 实时活动 | 待确认 | 本期给陪跑员端做（见 04） | 出发和汇合阶段陪跑员主要看锁屏 |
| D16 | 头卡状态色（v2） | 统一藏青 | 约好藏青、出发主蓝、汇合琥珀、跑步中青绿、完成绿 | 一眼分辨状态；颜色只在头卡上，所以不乱 |
| D17 | 跑步中（v2） | 沿用现有实现 | 按 08 重新设计：浅色页面、不看屏幕原则、无黄色主按钮 | 跑步中是产品的核心场景 |
| D18 | 跑步中结束按钮（v2） | 黄色「长按 2 秒，结束陪跑」 | 白色次要按钮，长按时填黄 | 跑步中 99% 时间不想结束，视觉重心应在距离上 |
| D19 | 节奏信号（v2） | 无 | 跑者可发「稍慢一点 / 刚刚好 / 可以快一点」 | 跑者能表达节奏，陪跑员不用问 |
| D20 | 跑步中求助面板与暂停（v2） | 无 | 求助面板：暂停、走散响铃、联系值班、长按 3 秒紧急求助 | 大多数"需要帮助"不是紧急事件 |

## 二、保持 v3 不变（本期不要改）

- 开始跑步：双方都能按，先按的生效
- 到达判定：进入集合点 100 米推送询问「到了吗」，不自动判定到达
- 志愿时长：从开始跑步算到结束陪跑，按 0.1 小时取整，组织 10 个工作日内确认
- 临时取消（12 小时内）、晚到 3 分钟自动通知跑者、等满 15 分钟可结束等待、跑者取消不算陪跑员
- 出发提醒：**建议出发时间前 5 分钟**发时间敏感推送。注意：画板上写的是「6:25 会提醒你出发」（前 10 分钟），**以 v3 为准，实现为 6:30**
- 提示级别矩阵、禁止项（不做 App 内地图、不出现抢单 / 排行 / 升学 / 评优字样、一屏只有一个黄色主按钮、取消类用灰色文字）
- D1 取消确认单的交互与文案（跑步中 v2 已纳入本期，见 08）

## 三、待产品确认（实现时按"保持 v3"处理，并留好扩展点）
