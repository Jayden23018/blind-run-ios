# 助盲跑 · 跑步中与跑后 · 状态清单

v1 · 2026-09-16 · 目标平台：原生 iOS（SwiftUI）· 画布 iPhone 390×844pt

每个状态给出五项：界面元素 / VoiceOver 标签 / 播报文案 / 触发条件 / 播报优先级。
取值与文案以本清单为准；颜色与尺寸对齐仓库 `AppColors.Flow`（FlowPalette.swift）与 `FlowMetrics`。

## 全局规则

**提示音**：前置音（单声 0.3 秒，每公里与按需播报前）· 注意音（两声短音，无震动，电量）· 警示音（三连音 + 强震，走散 / 离线）· 紧急倒计时音（已有）。

**优先级**：紧急求助 > 警示 > 对方操作 > 按需播报 > 每公里播报。

**防叠声**：一次只播一条并按优先级排队；按需播报打断排队中的每公里播报；每公里播报排队超过 10 秒丢弃；音乐只压低不暂停；通话中只保留警示；语音不移动读屏焦点。

**不变量**：主按钮位置永不变化，只换文字与图标；每屏只有一个黄色主按钮 + 「求助与安全」，通栏上下排列；可点区域 ≥64pt；数字一律等宽；正常状态不提示，异常才提示（判据＝跑者听到后能不能做点什么）。

**禁止项**：地图 · 暂停按钮 · 并排按钮 · 五星评分 · 锁屏上的结束或求助按钮 · 非紧急场景使用实心红。
