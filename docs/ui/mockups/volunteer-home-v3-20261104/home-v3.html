为什么 v2 不好看

v2 把接单页的内容（接单状态、下一次陪跑、待确认预约）搬上了首页，同时删掉了 v1 的徽章、最近陪跑、评分卡。首页既混进了接单，又变空了，改动也超出了「在 v1 上改」。

一个例外要你定

「预约待确认」有 60 分钟期限，10-17 你定过放在首页（#463），09-06 调研的结论也是「确认按钮直接摆在卡上，不进二级页」。v3 没动它：有待确认时它仍出现在首页最上方，确认后消失。要不要也挪进接单页，你定。

实现前要核的

最近陪跑卡要多发一次「跑后记录月度列表」请求（「记录」标签页已在用同一个接口），契约里有 distanceM、陪伴时长、对方脱敏姓名；路线缩略图 thumbnail 只给陪跑员，超过 90 天或轨迹不足时为空，那时右侧不画图。
