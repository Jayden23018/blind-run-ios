填写视力状况前，请先确认

视力状况和是否使用导盲犬属于敏感个人信息，填不填由你决定。

它只用来让陪跑员知道该怎么准备：你能不能看见他挥手、要不要带牵引绳。它不参与排序打分。

陪跑员在接单前就能看到这两项，包括最后没有接你单的那些人。这是为了让他到场前能做好准备。

不填也能约跑。你可以只告诉陪跑员希望怎么被引导，那一项不需要单独同意。

和参考图不一样的地方（都是盲人端规定，不是随手改）

  1. 选项行 64pt 高（参考 52pt）；「继续」胶囊看得见的 52pt，左右各距屏 28pt（#749 定稿）。
  2. 视力同意页两个一样大的按钮（参考只有一个「现在开始」）。
  3. 只有视力卡有说明页；其余卡点「设置」直接进第 1 题。每多一页，读屏用户就要多划好几下；「谁会看到」已写在每道题下。
  4. 题号「第 1 题，共 2 题」：参考图没有，读屏用户看不到进度条，需要这句话。

读屏怎么走

  • 换到下一题，焦点自动放到题目上，先念题号和题目。
  • 选项念「牵引绳，已选中，第 1 项，共 4 项」。
  • 「继续」灰时念「变暗」，并提示「请先选择一项」。
  • 保存后念「已保存：…」，焦点放到那张卡上。

11-06 已定的 3 件事

  1. 卡片图标用彩色，只取全局语义色（绿 / 蓝 / 橙 / 灰 / 红）：草稿里的天青、靛蓝、琥珀是陪跑员首页专用色，实现时换掉。
  2. 只有视力卡有说明页（同意页）。
  3. 「其他需求」（可多选，至少选一项）：途中需要休息、跑前需慢走热身、定时提醒补水、尽量选择安静路线、请提高音量、放慢语速、无其他需求（与其他项互斥）。不列疾病，避开敏感健康信息。
