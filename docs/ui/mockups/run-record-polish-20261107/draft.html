第 3 项　跑步详情右上角的声音按钮：和返回键同样式、对称

原因：返回键是系统导航栏画的；声音按钮是自己叠在页面上的（RunRecordFitnessMap.swift:57-61），上边距用的是「状态栏 + 导航栏」的总高度，所以落在导航栏下面；它的圆又是 44pt 居中放在 64pt 的可点框里，又往下、往左各偏了 10pt。样式也不同：返回键是系统玻璃圆，声音钮是白底蓝图标加阴影。

改后声音钮放进导航栏右边（ToolbarItem(placement: .topBarTrailing)）。系统自己把它画成和返回键一样的玻璃圆，左右对称、同一高度，往上滑也一起留在顶上。播放时图标换成停止。
这样改的好处：不用自己算位置，换手机尺寸、横屏、灵动岛都对得齐；以后苹果改导航栏样式，两个钮一起变。
代价（需要你知道）：① 可点区跟返回键一样，是系统的大小（约 44pt），比项目规定的盲人端 64pt 小。返回键本来就是这个大小；开着读屏时这颗钮本来就不显示（读屏走头部后面那个隐藏的「听这次跑步」），所以影响的是不开读屏的低视力用户。② iOS 16–25 上导航栏按钮没有玻璃圆，会和返回键一样只显示图标，仍然对称。
不想要 44pt 的话：可以保留自己画的钮，只把位置算到和返回键同一中线、样式换成玻璃圆，可点区仍 64pt。缺点是要自己算位置，换机型可能差一两个点。
顺带：没有地图的那种详情页（轨迹不够画不出地图）里，声音钮现在放在页面内容右上角，也会一起挪进导航栏。陪跑员端详情页没有这颗钮，不受影响。
