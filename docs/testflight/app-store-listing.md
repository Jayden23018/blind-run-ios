## 3. 年龄分级问卷

照实回答。下面几题要注意，其余内容类（暴力、色情、赌博、恐怖等）一律选「无」：

| 问题 | 答 | 理由 |
|---|---|---|
| Shared Location（与他人共享真实位置） | 是 | 陪跑员出发后，双方互相看到位置（Apple 2026-11-16 新增的必答题） |
| 消息与聊天 / 用户之间的交流 | 是 | 跑后双方可以互相留言 |
| 用户生成内容 | 是 | 同上，留言是用户写的文字 |
| 医疗或健康话题 | 否 | 只记录步数、步频、爬升，不给医疗建议 |
| 不受限的网页访问 | 否 | App 内只打开自己的隐私政策和用户协议 |
| 广告 | 否 | 无广告 SDK |

### 5.2 描述

只写本构建里真有的功能（`docs/pre-launch-checklist.md` §B1）。

```text
助盲跑帮视障跑者预约志愿陪跑员，一起出门跑步。

【跑者】
· 用语音或读屏说出出发地点和时间，就能预约陪跑。整个 App 按 VoiceOver 设计，跑者端所有操作都能不看屏幕完成。
· 陪跑员接单后，App 会念出「正在赶来」「已到达」等进度，你不用盯着屏幕等。
· 跑步中有节奏提示，可以暂停；跑完生成跑步记录。
· 可以设置紧急联系人。陪跑进行中遇到情况，可以一键求助：平台客服会收到提醒，并尝试联系你的紧急联系人。

【陪跑员】
· 通过人脸核验和人工审核后可以接单。
· 打开接单开关、保持 App 开着，就能收到附近的陪跑邀请。
· 出发后共享位置，方便跑者知道你到哪儿了。

【开放范围】
目前只在深圳提供，每天 07:00 至 21:00 可以开跑。开始时间需在 30 分钟之后、30 天之内。

【请注意】
求助功能不能代替拨打 110 或 120。遇到紧急情况，请先拨打急救或报警电话。
```
