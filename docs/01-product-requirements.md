# 01 — 产品需求文档 (PRD)

## 产品名称

**助盲跑 (AidRun)** — 连接盲人跑者与志愿者的户外跑步协助服务平台。

## 产品定位

助盲跑是一款面向盲人跑者与志愿者的双角色移动产品，目标是在户外跑步场景中建立安全、可预约、可追踪的协助服务闭环。

当前版本（MVP）聚焦**预约型服务**，不以即时呼叫为首要目标。产品形态为 iOS App，按角色进入不同流程：

- **盲人端**：强调极简触控、低认知负担、关键节点语音播报。
- **志愿者端**：强调接单与服务执行闭环。
- **平台侧**：优先保障订单闭环与安全可追踪性。

## 项目背景

- **项目类型**：公益项目展示 / 学生项目 / 比赛作品。
- **目标用户**：未来可以面向潜在真实用户和跑者展示。
- **第一版目标**：3 天内完成可演示版本，而非生产级完整系统。

## 目标用户与角色画像

### 角色 A：盲人跑者

| 维度 | 描述 |
|------|------|
| 核心需求 | 安全地完成户外跑步，获得志愿者协助 |
| 痛点 | 导航障碍、障碍物规避、安全隐患 |
| 典型场景 | 提前预约志愿者，在约定时间地点会合，共同完成跑步 |
| 技术依赖 | 高度依赖语音交互（VoiceOver + TTS），触控操作为辅助 |

### 角色 B：志愿者

| 维度 | 描述 |
|------|------|
| 核心需求 | 通过结构化渠道提供帮助，获得积分奖励 |
| 痛点 | 缺乏与盲人跑者对接的便捷渠道 |
| 典型场景 | 浏览附近订单，接单后查看出发点位置并前往会合，全程陪伴跑步 |
| 激励 | 每完成一次服务获得 +100 积分（MVP 阶段积分仅展示） |

### 暂不作为独立角色

- 管理员
- 紧急联系人
- 机构 / 公益组织

> 注：后端保留管理员审核相关字段，为后续扩展做准备。

## 核心价值主张

- **对盲人跑者**：可预约的陪伴式跑步协助，紧急求助安全保障，极简无障碍交互。
- **对志愿者**：有意义的公益参与，积分激励体系（MVP 展示占位），灵活的时间安排。

## 第一版成功标准

1. 能完整演示：**盲人预约 → 志愿者接单 → 志愿者到达 → 盲人确认开始服务 → 志愿者结束服务 → 盲人看到完成状态**。
2. 必须接入真实地图（高德地图）。
3. 必须接入真实定位。
4. 必须接入真实用户登录。
5. 必须体现无障碍体验，包括 VoiceOver、TTS、极简大按钮。

## 第一版优先级

优先级字符串：**CABFDEGH**（从高到低排列）

| 优先级 | 功能模块 |
|--------|----------|
| C | 订单闭环 |
| A | 手机号登录 + JWT |
| B | 高德地图 + 定位 |
| F | VoiceOver 无障碍优化 |
| D | TTS 语音播报 |
| E | 语音输入 |
| G | 积分商城占位 |
| H | 星级评分 |

## 关键技术约束

| 约束项 | 决策 |
|--------|------|
| 客户端 | Swift 原生 iOS，SwiftUI + MVVM |
| iOS 版本 | iOS 16+ |
| 后端 | Spring Boot（独立项目） |
| 数据库 | Demo 用 H2，后续迁移至 PostgreSQL |
| 网络层 | URLSession + async/await |
| Token 存储 | MVP 用 UserDefaults（正式版替换为 Keychain） |
| 地图服务 | 高德地图（AMap） |
| 实时通信 | REST + WebSocket；订单页保留每 5 秒轮询作为 WebSocket 断开时的降级方案 |
| 短信验证 | MVP 使用固定验证码 `123456`，不接入真实短信服务商 |
| 志愿者认证 | Mock 认证，非真实实名认证 |
| 环境切换 | 支持 Mock / Local Backend / Production Backend 三种模式 |
| 主题 | 支持系统深色 / 浅色模式，优先保证可读性和对比度 |

## 显式排除项（Non-Goals）

以下功能明确不在 MVP 范围内：

- Android 客户端
- 完整管理员后台
- 真实短信服务
- 真实实名认证
- 真实管理员审核后台
- 实时轨迹共享
- 自动拨打电话 / 发送短信
- AI 助手 / 复杂自然语言时间解析
- 路线导航
- 完整积分商城（仅占位）
- 支付 / 库存
- App 内聊天 / 虚拟号码
- 复杂风控 / 摔倒检测 / 电子围栏
- 即时呼叫
- 多人活动报名

## 技术栈

### 客户端

```
Swift 原生 iOS
├── SwiftUI（必要时桥接 UIKit）
├── MVVM 架构
├── URLSession 网络层
├── 高德地图 SDK（AMap3DMap / AMapSearch / AMapLocation）
├── AVSpeechSynthesizer（TTS）
├── Speech Framework（语音输入）
└── UserDefaults（token 存储）
```

### 后端

```
Spring Boot
├── H2 数据库（Demo）
├── PostgreSQL（后续）
├── REST API
├── Swagger / OpenAPI 文档
└── 启动时 seed 测试数据
```
