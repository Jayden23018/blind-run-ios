# 公安联网备案（App）要填什么、怎么交 — 2026-11-05

问题：助盲跑 App 备案号 `粤ICP备20047259号-4A`（2026-10-29 通过）之后，公安联网备案的流程、材料、「运行截图」和「功能描述」怎么准备。截止日 2026-11-28。

## 结论

1. 入口是全国互联网安全管理服务平台 `https://beian.mps.gov.cn`，路径「业务办理 → APP 业务 → 新增 APP」，分三步：开办主体 → APP 信息 → 提示说明（网络安全责任告知书）→ 提交。
2. **APP 信息页的字段**（从平台前端代码 `web/assets/app.data.5eb831cc.js` 原样取得，2026-11-05）：

| 字段 | 必填 | 限制 / 说明 |
|---|---|---|
| 应用名称 | 是 | 与 ICP 备案名一致：助盲跑 |
| 运行平台 | 是 | 多选：Android / IOS / Windows Phone / 鸿蒙 / linux / 黑莓 / windows / macOS / 其他 |
| 应用 logo | 是 | 1 张，≤ 2 MB |
| 应用类型 | 是 | 树形多选，选项来自登录后的字典 `jgdcfl`，未登录取不到（未核实具体选项） |
| 应用包名 | 是 | 多个用英文逗号分隔 |
| 市值 / 月活用户数量 / 注册用户总量 | 否 | 数字，可不填 |
| 相关前置许可 | 是 | **默认选中「是」**，不涉及要手动改成「否」 |
| 运行截图 | 是 | **1–6 张**，每张 ≤ 5 MB，一次传一张 |
| 功能描述 | 是 | 多行文本，前端无字数上限 |

   平台提示文案原文列出同一组：「应用名称、运行平台、应用logo(图片)、应用类型、应用包名、月活跃用户数量、注册用户总量、相关前置许可、运行截图（1~6张图片）、功能描述」（`ApplicationForm.58c4b074.js`）。
3. 同一文件里还有一组「版本」字段：所属应用市场、版本号（必填）、上线时间、下载地址（选填）、文件包 md5 或 sha1（必填）、功能描述（必填，示例「修改了什么功能」）、运行截图 1–6 张。它属于登记版本的表单，不在新增 APP 的三步向导里；什么时候要填未核实。
4. **开办主体**（单位）要：主办单位名称、证件类型与号码、有效证件（营业执照）、办公地址、法定代表人姓名；负责人姓名、证件号、有效期、**身份证人像面 + 国徽面 + 手持**（png/jpeg/jpg，≤ 5 MB）、常住地址、手机号。来源：官方《网站备案常见问题》第 5 条 + 阿里云指南截图。
5. 单位要用**法人账号**登录，或由法定代表人账号设置「经办人」后用个人账号办（阿里云指南「经办人登录设置」）。注册、登录都要用「公安一网通办」App 扫码实人认证。
6. 审核：由**单位办公地址所属公安机关**审核，时限 30 个自然日；可能要求**当面核验**或**实地检查**；提交后 30 分钟内可撤回。主体不单独审核，必须和至少一个 App 业务一起提交。
7. 「是否提供互联网交互服务」：阿里云对交互式的定义是「用户与用户之间或用户与平台之间交流互动」，含留言板、在线聊天、用户评论。助盲跑有订单匹配、给陪跑员看的跑者备注、举报与客服工单，按定义应选「是」。不确定时阿里云建议先选否、被驳回再改；我们按实情选是。
8. 告知书第五条：「具有舆论属性或社会动员能力的互联网信息服务应当履行安全评估义务」。助盲跑没有公开发帖、评论区，按字面不属于这一类；以属地公安审核意见为准。
9. 审核通过后要在 App 显著位置展示公安备案号。官方示例是网页底部 HTML 代码；App 里的展示位置与工信部备案号放在一起（#620 的「关于」页）是合理推断，未找到 App 专门要求。备案号格式：省简称 + 公网安备 + 6 位属地代码 + 2 位标注位 + 6 位顺序码。

## 运行截图怎么选

- 本机现有截图（`~/Documents/aidrun-design-archive/2026-11-04-volunteer-home-v3/current/` 等）**全部带状态栏「Mock 本地模拟」角标**，名字是「测试盲人 / 测试志愿者」，预约页还写着「正在使用演示坐标」。**不能直接交**：截图要证明 App 真实在运行，Mock 标识会让审核人员判断成演示版。
- 要用正式包（生产后台）在真机重截。建议 4 张，覆盖两种角色和主流程：
  1. 盲人端首页（「预约新的陪跑」大按钮）
  2. 创建预约确认页（地点、时间）
  3. 陪跑员端首页（接单开关、陪跑统计）
  4. 订单进行或完成页（双方匹配后的状态）
- 不交：求助页、星火页（含地图，审图号问题另有记录）、带真实手机号或身份证信息的页面。
