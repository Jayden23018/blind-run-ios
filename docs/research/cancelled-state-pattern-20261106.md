# 已取消页怎么做（2026-11-06，#818）

## 问题
盲人端取消订单后落在改版前的只读列表上，和订单页其他状态不是一套。新页该怎么做、要不要自动离开？

## 查到的

|---|---|---|
| Apple HIG《Feedback》（developer.apple.com/design/human-interface-guidelines/feedback；本次只读到搜索摘要与镜像，未逐字抓原文） | 状态用被动方式展示；重要操作完成后给确认；弹窗只给重要且可操作的信息 | 取消成功后停在页上给确认，不弹窗、不自动返回 |
