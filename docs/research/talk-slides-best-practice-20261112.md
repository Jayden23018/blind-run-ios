# 30 分钟大会演讲的幻灯片怎么做（2026-11-12）

用途：COSCon'26 青少年论坛 30 分钟 Talk，必须用组委会模板。成品不在仓库里（在本机设计存档 `2026-11-12-coscon26-talk-deck/final/`）。

## 结论

| 做法 | 依据 | 本次怎么用 |
|---|---|---|
| 一页只讲一件事，标题写成一句完整的结论 | Harvard 公卫学院、MIT CommLab、Penn State（Michael Alley 的 assertion-evidence 方法） | 每页标题都是一句话，例如「系统一次邀请 3 位陪跑员，谁先接就是谁」 |
| 标题下面放证据（图），少放文字 | Harvard Catalyst；Penn State | 功能页左边放真机截图，右边最多 4 条短句 |
| 大约一分钟一页 | Harvard Catalyst（经验值，有人认为信息少的页可以更快） | 25 分钟正讲，24 页（含 4 个章节页），留 5 分钟提问 |
| 正文 ≥ 24pt、标题 ≥ 36pt（大会场） | UC Merced、Texas A&M；另一来源给 ≥ 18pt | 模板空间有限，正文用 16–22pt、标题 30pt，说明文字最小 13pt。⚠️ 低于上面的 24pt 建议 |
| 对比度：正文 4.5:1，大字 3:1 | WCAG AA（来源页有写成 4:5:1 的笔误） | 深藏青字放在浅底上 |
| 开场用具体场景，不先抛论点；按「开端—冲突—解决」讲 | AhaSlides 的 TED 结构、iThome | 从路跑比赛遇到盲人跑者讲起 → 配对难 → 产品 → 踩坑 → 进展 |
| 准备备用页，放在致谢之后 | 少数派 | 致谢后放系统架构图、订单状态图两页 |
| 不照着幻灯片念；备注写讲稿 | presentations.ai、少数派 | 每页演讲备注都标了时间点 |

## 没查到的

- 没有专门针对「技术大会 30 分钟」的系统指南，多数来源是 TED 或学术报告的通用建议。
- 「assertion-evidence 能提高 32% 记忆」只见于一份讲义，没有核实，不引用。
