# Legacy Local Backend

This local Spring Boot backend is archived as a historical implementation reference.

It does not match the active cloud contract in `docs/api_spec.yaml`, `docs/test-accounts.md`, and
`docs/websocket-protocol.md`. Current iOS integration and validation must target the cloud backend at
`http://47.114.113.171`.

Do not use this directory as the source of truth for endpoint names, request bodies, response bodies,
order status transitions, or WebSocket behavior.
