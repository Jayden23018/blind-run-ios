## Context

- iOS 26.2 SDK 对 `CLAccuracyAuthorizationReducedAccuracy` 的注释：精度约 5 公里，样本是区域代表点，最旧可能 20 分钟（`gate-blind-location-on-precise-accuracy/design.md` 已核对）。
- 同行会话每 5 秒发一次 `LOCATION_UPDATE`（`LiveEscortSessionCoordinator.sendLatestLocation`），样本来自 `LocationService.latestEscortBackendSample`，只看权限、错误与样本年龄，不看精确位置开关。
- 接收端按对端位置算距离、方位与走散告警；上行报文没有采样时间，也没有「这是模糊点」的标记（`hAcc` 有，但对端当前只用它放宽方位扇形）。
- #406 让「播报我的位置」在精确位置关着时不读本机、不问服务端，但留了两个窗口会退到服务端兜底，而服务端那份是关着时上报的模糊点：
  ① 刚打开精确位置、本机样本被清空的几秒；② 关着时把定位权限整个改成「不允许」，`isPreciseLocationOff` 变 false。
- 临时精确位置：`requestTemporaryFullAccuracyAuthorization(withPurposeKey:)` 的键必须在 `NSLocationTemporaryUsageDescriptionDictionary` 里，否则系统不弹；开着后台定位指示器的会话期间不过期。

## Goals / Non-Goals

**Goals:**
- 精确位置关闭时，两端都不上报同行位置；恢复后自动恢复，不需要重进页面。
- 两端都可见可听地知道「位置共享暂停了、为什么、怎么恢复」。
- 会话开始时为两端各申请一次临时精确位置。

**Non-Goals:**
- 不改派单位置上报（`ContentView.reportWebSocketLocationIfNeeded`）：#407 列的三处不含它，另记 issue。
- 不改陪跑员端代发求助（#407 第 1 项，归另一个变更）。
- 不改语音下单消歧（#407 第 3 项，保持现状，理由见决定 4）。
- 不改后端契约（不加「模糊点」标记）。

## Decisions

1. **闸放在协调器的发送函数上，不放进 `latestEscortBackendSample`。** 健康判定要先认出「精确位置关闭」这个原因再落到「位置暂时不可用」，
   样本函数若直接返回 nil，原因就被盖住了。发送函数和健康判定读同一个 `isPreciseLocationOff`，两处不会漂开。
   - 替代方案：后端加 `reducedAccuracy` 标记、对端自己判。被否：要改契约，而对端拿到一个偏 5 公里的点除了「不用」也没有更好的用法。
2. **两端同一档健康状态，文案按角色分。** `LiveEscortHealthState.preciseLocationOff` 带上角色：盲人端说求助发不出去、陪跑员看不到你；
   陪跑员端说对方看不到你的位置、走散提醒会暂停。两句都以「已暂停同行位置共享」说清这一端已经不发了，并给出恢复办法。播报沿用根视图对健康档位变化的那一次朗读。
3. **临时精确位置两端都申请，用途键分开。** 时机沿用盲人端先例（出发时一次，进 `IN_PROGRESS` 仍关着再一次，按「订单 + 阶段」去重）。
   陪跑员端新增用途键 `AidRunEscortVolunteer`：盲人那条写的是「跑步中的紧急求助才能带上你的准确位置」，对陪跑员不成立。
4. **语音下单消歧保持现状（#407 第 3 项）。** 用户在系统里选「大致位置」，本来就是允许 App 拿大致位置做附近搜索；
   消歧只在约 50 公里半径里给同名地点排先后，5 公里误差不改变结果，而且这个坐标不当出发点（出发点在精确位置关闭时已被 #380 拦住）。
   拦掉它只会让同名地点的追问变多，对隐私没有增益。
5. **#406 的两个窗口随之消失，不另加判据。** 关着时不再上报，服务端就不会存下模糊点；兜底读到的只可能是关之前的精确点（按 `ageSeconds` 说清新鲜度）。

## Risks / Trade-offs

- 拒绝临时精确位置的用户，这一单对方看不到他的位置、走散提醒不工作 → 横幅常驻并播报，说清后果与恢复办法；跑者端求助本就因精确位置关闭而发不出去（#380），文案已给 110 / 120。
- 陪跑员关了精确位置，盲人端看到的是「对方位置暂不可用」而不是原因 → 原因只在陪跑员自己那端说；对端只知道没有新位置，这与网络中断时一致。
- 系统可能不弹临时精确位置（App 在后台等）→ 文案写「如果弹出提示请选允许」，并给出系统设置的路径。
