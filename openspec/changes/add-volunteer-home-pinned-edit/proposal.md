## Why

负责人 2026-11-04 看了陪跑员首页 v3 的真机截图（#694，PR #696）后提出四处修改：最近陪跑卡右侧只是一条折线草图，看不出在哪里跑；页顶没有样例里的天蓝渐变；「置顶」旁的「编辑」没做；陪伴时长要天青色、连续陪跑与评分要两种颜色。「编辑」负责人选了「选卡片 + 拖动排序」。

## What Changes

- 首页分区标题改为「置顶」，右侧「编辑」进一页：可以把陪伴时长、连续陪跑、评分、最近陪跑、徽章五张卡加入或移出置顶，并拖动排序；只存在本机，不上后端。读屏用户可用「上移 / 下移」动作排序。
- 最近陪跑卡的路线改为高德真实地图上的轨迹（起点、终点、路线），整条宽图放在卡片里；`thumbnail` 为空仍不画。
- 页顶加天蓝渐变（亮 `#CFE3F7` → `#E7EEF6` → 页面底色），暗色有对应的深色渐变。
- 卡名色：陪伴时长天青 `#0A6B72`，连续陪跑 / 固定搭档橙 `#C2410C`，评分琥珀 `#9A5B00`，亮暗两套都有对比度用例。
