## Why

两轮界面迭代后零上下文复评：盲人端 6.3 / 6.9 / 5.0、志愿者端 6.7 / 7.1 / 5.5（美观 / 易用 / 吸引力）。
打分员第二轮列了「最该改的 10 处」（`docs/review/ui-aesthetic-scoring-20261005.md` 末节）。逐条对代码与决定源核对后（issue #325）：

- 假象 3 条：陪跑完成页缺本次数据（巡游从长按结束进来，Mock 不带完赛三项；真实数据下头卡有「第 N 次一起跑」与里程 · 时长）、跑者完成页「本次路线」下为空（视口切在标题下 + 巡游关地图）、语音「聆听中」与待说态一样（截的是 UI 测试接缝 `AIDRUN_UI_TEST_FORCE_VOICE_STAGE`，真录音态有独立图形与标题）。
- 与已拍板决定冲突、负责人 2026-10-06 定「保持现状」：跑者跑步中隐藏标签栏（③ 藏了返回箭头，标签栏是唯一出口）、空首页留白（`blind-order-flow/PROMPT.md:142`）。
- 不改：陪跑完成页「求助」（AGENTS §6）、「我已经出发了」描边（`volunteer-order-page-v2/02-ios-screens.md:79`）、订单页最后一行被切（滚动视口边缘，底栏不遮内容）。
- 其余五处改。

## What Changes

- 国标星级卡：陪跑完成页与成就页改用首屏的正向说法（未达一星时「距离一星还差 N 小时 / 已累计 X / 100 小时」），三处一份文案（负责人 2026-10-06）。
- 志愿者首屏派单状态卡：删完成 / 评分两格（同屏已有）、接单率与派单 · 接受 · 拒绝 · 超时计数（像考核，负责人 2026-10-06）；状态句不再重复作业区已画成整卡的原因（培训、资质），全被说过时只剩覆盖范围。
- 跑者完成页：「提交评价」与提交后的「返回首页」从实心改为描边次按钮，底部「完成」是唯一实心按钮。
- 志愿者通话确认页：截止时刻提成单独一行正文（「今天 23:51 前完成通话确认」），时间行用邀请页同一相对日期写法；「不合适」不再用红色，改描边。
- 登录页「获取验证码」禁用态：字色 `textSecondary` 压 `systemGray5`（亮 5.3:1 / 暗 6.3:1，原 1.52:1）。

## Non-goals

- 不加排行、比较、成就弹层；不新增颜色 token。
- 不加感谢语、说明小字来「填满」页面（design-direction §7）。
