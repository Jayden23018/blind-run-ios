## 决策

1. **取整向下**：`km = max(0, meters) / 1000`（整数除法），与首屏 `hours()` 同一个「少算不多算」方向。12_999 米显示 12 公里，不是 13。
2. **km == 0 时回落到次数，不显示「0 公里」**：后端口径写明 2026-08-14 之前完成的订单没有里程快照、按 0 算，所以「有完成订单但里程为 0」是真实存在的状态；对志愿者显示最大最粗的 0 是负激励，与新人态不显示「0 次」是同一条判据。
3. **次数不丢**：公里成为主指标后，三列统计里没有完成次数，所以主指标下加一行「共 M 次陪跑」。
4. **新人态只看 `totalCompleted`**：里程 > 0 但完成次数为 0 / 缺失不成立（后端里程来自已完成订单），若发生按新人态处理，不信里程。
5. 只用 `AppFonts` / `AppColors` 既有 token，不加强调色、不加图标；文案只陈述，不带激励句式。
