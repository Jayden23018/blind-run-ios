## 简介
本指南面向参与 blindRun iOS 项目的开发者，提供从零开始的开发环境准备、Xcode 与 Swift 语言要求、高德地图 SDK 配置、API 环境（mock、localBackend、production）的配置与切换机制、以及项目初始化与常见问题的解决方案。文档同时整合了最新的质量保证流程，包括 OpenSpec 规范验证、后端测试和 iOS 构建验证命令，帮助团队快速达成可演示的 MVP。

### API 环境配置与切换机制
- 环境类型
  - mock：本地假数据，用于 UI 与流程调试
  - localBackend：局域网连接 Spring Boot 后端（例如 http://192.168.x.x:8080）
  - production：保留用于后续部署
- 实现建议
  - 定义 APIEnvironment 枚举或结构体，包含 baseURL 与显示名称
  - 使用统一的 APIClient 协议，使 Mock 与真实实现共享调用点
  - 在 Debug 构建中暴露小型环境选择器（可在设置页或启动配置中）
  - 令牌持久化在 UserDefaults（MVP），生产前迁移至 Keychain

## 多媒体处理工具配置

### ffmpeg 视频帧提取配置
项目集成了 ffmpeg 用于视频帧提取功能，支持将视频文件转换为图像序列，便于演示和测试。

- **配置位置**：`.claude/settings.local.json`
- **命令示例**：`ffmpeg -i "/Users/jerry/B/blind run/demo.mov" -vf "fps=1/10" -frames:v 20 "/tmp/demo_frame_%03d.png"`
- **功能说明**：
  - 将输入视频按指定帧率提取为 PNG 图像
  - 支持自定义输出帧数和图像格式
  - 输出路径可自定义，建议使用临时目录

### Python 自动化脚本执行
项目支持 Python 脚本执行，用于自动化测试和数据处理任务。

- **配置位置**：`.claude/settings.local.json`
- **命令示例**：`python3 -c ':*)`
- **功能说明**：
  - 支持执行 Python 3 脚本
  - 可用于自动化测试、数据验证和批处理任务
  - 建议使用虚拟环境隔离依赖

### bash 权限管理
Claude AI 代理的 bash 权限通过 `.claude/settings.local.json` 文件管理，确保安全的命令执行。

- **权限配置**：
  - `Bash(git:*)` - Git 相关命令
  - `Bash(ffmpeg ...)` - 视频帧提取命令
  - `Bash(python3 -c ':*)` - Python 脚本执行
- **安全考虑**：
  - 仅允许预定义的安全命令
  - 避免执行任意 bash 命令
  - 建议定期审查权限配置

## 性能考虑
- 轮询策略：订单状态轮询周期为 5 秒，仅在特定状态与可见页面内进行，避免无谓开销
- 网络层：使用 URLSession + async/await，减少额外依赖，提升可维护性
- 地图与定位：在 iOS 端计算距离并排序，避免后端复杂度；定位失败时使用演示回退坐标
- 令牌存储：UserDefaults 简化 MVP，生产前迁移至 Keychain 以提升安全性
- **多媒体处理**：ffmpeg 视频帧提取可能消耗较多 CPU 和磁盘 I/O，建议在后台线程执行并限制并发数量
- 质量保证：通过自动化验证减少回归问题，提升整体性能稳定性

## 故障排查指南
- 高德地图相关
  - 若地图不显示或定位失败：检查 LocalConfig.xcconfig 是否正确配置密钥；确认已添加至工程且未被提交到版本库
  - 演示回退坐标：当设备定位不可用时，使用演示坐标保持演示稳定
- API 环境切换
  - Debug 构建下无法切换环境：确认已在设置或启动配置中暴露环境选择器；核对 API 环境枚举与 baseURL 配置
  - 本地后端连接失败：确认后端运行在与设备同一局域网，并使用正确的 LAN 地址（如 http://192.168.x.x:8080）
- 令牌与认证
  - 登录后无令牌或过期：检查 UserDefaults 中的 JWT 存储；生产前迁移至 Keychain
- 版本与兼容性
  - iOS 版本过低：确保目标系统版本为 iOS 16+；低于该版本将无法运行
- OpenSpec 验证失败
  - 检查 OpenSpec 规范是否最新，确保所有模块都符合当前规范
  - 验证命令：`openspec validate add-aidrun-ios-spring-mvp --strict --no-interactive`
- 后端测试失败
  - 检查 Gradle/Maven 构建是否通过：`./gradlew test` 或 `./mvnw test`
  - 确保所有 API 端点都有相应的测试用例
- iOS 构建失败
  - 检查 Xcode 版本是否满足 iOS 16+ 要求
  - 验证构建命令：`xcodebuild -scheme <AppScheme> -destination 'platform=iOS Simulator,name=iPhone 15' build`
- **多媒体工具故障**（新增）
  - ffmpeg 命令执行失败：检查 ffmpeg 是否正确安装，确认输入视频路径和输出目录权限
  - Python 脚本执行失败：检查 Python 3 环境，确认脚本语法和依赖库
  - bash 权限配置错误：检查 .claude/settings.local.json 中的权限配置，确保命令格式正确
