## 简介
本文件面向 blindRun iOS 应用的开发者，系统性说明应用的环境配置方法与最佳实践。重点涵盖**构建通道系统**（Development、Demo、Production）的配置与使用场景；**智能环境解析机制**（结合构建通道的环境映射）；三类 API 环境模式（Mock、Local Backend、Demo Cloud、Production Backend）的配置与使用场景；高德地图 API 密钥的管理方式（LocalConfig.xcconfig 的配置、密钥存储位置与安全注意事项）；环境变量与配置文件的加载顺序与优先级；不同开发阶段（开发、测试、生产）的配置差异；以及 .gitignore 的作用与敏感配置的安全管理策略。特别新增了对遗留 IP 地址配置的自动迁移支持和**智能环境映射**功能，确保从旧版本的 '192.168.1.100' 自动升级到新默认的 '127.0.0.1' 地址，以及将存储的旧版 "production" 环境自动映射到演示云环境的功能。文末提供完整的环境初始化与配置检查清单，帮助团队快速、安全地完成本地与联调环境搭建。

## 核心组件
- **构建通道系统**
  - Development：开发通道，支持所有环境（Mock、Local Backend、Demo Cloud），允许环境切换器。
  - Demo：演示通道，固定使用 Demo Cloud 环境，不允许环境切换器。
  - Production：生产通道，固定使用 Production Backend 环境，不允许环境切换器。
- **智能环境解析机制**
  - 结合构建通道和存储的环境设置进行智能解析。
  - 自动将存储的旧版 "production" 环境映射到演示云环境（非生产构建）。
  - 确保环境切换的合理性和安全性。
- API 环境模式
  - Mock：本地假数据，无需后端，适用于 UI 与流程调试。
  - Local Backend：局域网连接 Spring Boot 后端，适用于 Mac 本地运行后端并通过局域网访问移动设备。
  - Demo Cloud：演示云端环境，固定连接 http://47.114.113.171。
  - Production Backend：公网后端，为后续扩展预留。
- 高德地图密钥管理
  - 密钥存储于 LocalConfig.xcconfig 或本地 plist。
  - 本地配置文件加入 .gitignore，避免提交到版本库。
  - 提供 LocalConfig.example.xcconfig 说明所需键名。
- **IP 地址自动迁移机制**
  - 支持从遗留的 '192.168.1.100' 自动迁移到新的默认 '127.0.0.1'。
  - 通过 UserDefaults 检测现有配置，智能判断是否需要执行迁移。
  - 保持向后兼容性，确保老版本用户的无缝升级体验。
- 环境选择与加载
  - 在 Debug 构建中，可通过设置或启动配置暴露小型环境选择器。
  - localBackend 需支持类似 http://192.168.x.x:8080 的局域网地址。
  - 生产 URL 可先保留占位，待部署时再替换。
- 配置加载顺序与优先级
  - 文档建议通过统一的 APIEnvironment 定义 baseURL 与显示名称，并使用单一 APIClient 协议让 Mock 与真实实现共享调用点。
  - 通过 Debug 构建暴露的环境选择器动态决定当前环境。
  - 本地配置（如 LocalConfig.xcconfig）应被项目正确读取，确保密钥与后端地址分离。

## 详细组件分析

### 组件一：构建通道系统与智能环境解析
- **Development 通道（开发）**
  - 用途：日常开发调试，支持所有环境模式。
  - 权限：允许环境切换器，可自由切换 Mock、Local Backend、Demo Cloud。
  - 默认环境：Mock（便于离线开发）。
- **Demo 通道（演示）**
  - 用途：演示和测试，固定使用演示云环境。
  - 权限：不允许环境切换器，所有环境请求都会被映射到 Demo Cloud。
  - 默认环境：Demo Cloud（演示专用）。
- **Production 通道（生产）**
  - 用途：正式发布版本，固定使用生产环境。
  - 权限：不允许环境切换器，所有环境请求都会被映射到 Production。
  - 默认环境：Production（线上专用）。
- **智能环境映射**
  - 当存储的环境为 "production" 且构建通道不是 .production 时，自动映射到 .demoCloud。
  - 确保旧版用户在非生产构建中也能正常使用演示环境。

### 组件二：API 环境模式与加载流程
- **Mock 模式**
  - 用途：UI 与流程调试，无需网络后端。
  - 配置要点：在 APIEnvironment 中设置 Mock 的 baseURL；APIClient 的 Mock 实现负责构造假数据响应。
- **Local Backend 模式**
  - 用途：Mac 本地运行后端，移动设备通过局域网访问。
  - 配置要点：确保后端监听局域网地址（如 192.168.x.x），APIEnvironment 指向该地址；Debug 构建暴露环境选择器便于切换。
  - **IP 地址迁移**：系统会自动检测并迁移从 '192.168.1.100' 到 '127.0.0.1' 的配置，确保新旧版本的兼容性。
- **Demo Cloud 模式**
  - 用途：演示环境，固定连接 http://47.114.113.171。
  - 配置要点：固定演示服务器地址，无需用户配置。
- **Production Backend 模式**
  - 用途：公网后端，为后续扩展预留。
  - 配置要点：保留占位 URL，待部署后再替换为实际域名。

### 组件四：IP 地址自动迁移机制
- **遗留配置检测**
  - 系统会检查 UserDefaults 中保存的本地后端 IP 配置。
  - 检测值是否等于遗留的 '192.168.1.100'。
- **自动迁移逻辑**
  - 如果检测到遗留配置，自动将其迁移到新的默认 '127.0.0.1'。
  - 迁移后继续使用新的默认地址，确保开发体验的一致性。
- **向后兼容性**
  - 保持对现有配置的完全兼容，不会破坏已有的工作流程。
  - 新用户直接使用默认的 '127.0.0.1' 地址，无需手动配置。

### 组件五：环境变量与配置文件加载顺序与优先级
- **建议的加载顺序**
  - 项目启动时先确定构建通道（#if DEBUG、#elseif DEMO、#else）。
  - 读取存储的环境设置，进行智能映射（旧版 "production" 映射到 Demo Cloud）。
  - 根据构建通道解析最终环境（.development 允许所有环境，.demo 固定 Demo Cloud，.production 固定 Production）。
  - 读取 LocalConfig.xcconfig 中的地图密钥等本地键值。
  - 对于其他环境变量（如日志级别、遥测开关），可在同一配置层按需注入。
- **优先级原则**
  - 构建通道优先于存储的环境设置（Demo/Production 通道会强制固定环境）。
  - 旧版 "production" 环境在非生产构建中会被映射到 Demo Cloud。
  - Debug 环境下的用户选择优先于默认配置。
  - 本地配置（LocalConfig.xcconfig）优先于硬编码默认值。
  - **IP 迁移机制**：遗留配置会被自动检测并迁移，确保新旧版本的平滑过渡。
  - 生产环境的配置应通过外部注入（如构建参数或打包时替换）而非代码内嵌。

## 性能考虑
- **网络层**
  - 使用 URLSession + async/await，减少额外依赖，降低包体积与启动开销。
  - 避免在 Mock 模式下进行网络请求，减少不必要的延迟。
- **地图与定位**
  - 高德地图 SDK 初始化时仅加载必要资源，避免在 Mock 模式下初始化地图。
- **构建通道解析性能**
  - 构建通道解析仅在应用启动时执行一次，性能开销极小。
  - 通过编译时条件编译实现，运行时无额外开销。
- **IP 迁移性能**
  - IP 迁移操作仅在应用启动时执行一次，性能开销极小。
  - 通过 UserDefaults 缓存迁移结果，避免重复检测。
- **环境映射性能**
  - 环境映射操作仅在应用启动时执行一次，性能开销极小。
  - 通过字符串比较实现，运行时无额外开销。
- **轮询与实时性**
  - 订单状态轮询周期为 5 秒，兼顾演示实时性与性能消耗。

## 故障排查指南
- **无法加载后端 API**
  - 检查构建通道是否正确设置（#if DEBUG、#elseif DEMO、#else）。
  - 确认 APIEnvironment.baseURL 是否与后端监听地址一致（Local Backend 需支持局域网地址）。
  - 确认 Debug 构建中环境选择器已正确设置。
  - **IP 迁移问题**：如果遇到 IP 迁移相关问题，检查 UserDefaults 中的 'localBackendIP' 键值。
- **环境切换无效**
  - 检查当前构建通道是否允许环境切换器（仅 Development 通道允许）。
  - 确认智能环境映射是否正确工作（旧版 "production" 应映射到 Demo Cloud）。
- **地图功能异常**
  - 检查 LocalConfig.xcconfig 是否存在且未被 .gitignore 忽略。
  - 确认项目已正确读取 LocalConfig.xcconfig 中的地图密钥。
  - 检查 Info.plist 和 Info-Demo.plist 的配置键值引用。
- **配置泄露风险**
  - 确保 LocalConfig.xcconfig 已加入 .gitignore，避免提交到版本库。
  - 使用 LocalConfig.example.xcconfig 仅列出键名，不包含真实密钥。
- **IP 迁移故障**
  - 检查 UserDefaults 中是否存在遗留的 '192.168.1.100' 配置。
  - 确认 AppConstants.Defaults.legacyLocalBackendIP 常量值正确。
  - 验证新默认地址 '127.0.0.1' 的可达性。
- **演示通道问题**
  - 确认构建配置中已设置 DEMO 宏（#elseif DEMO）。
  - 检查演示通道的网络配置（Info-Demo.plist 中的 NSExceptionDomains）。
